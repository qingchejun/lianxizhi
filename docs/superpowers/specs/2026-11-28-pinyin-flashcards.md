# 拼音知识点闪卡（方案，2026-11-28）

站长 11-28 定：闪卡做「一张卡一个知识点」（不是算式卡、生字卡那种题海），先拿拼音试；
根据调研（docs/research/2026-11-28-flashcards-research.md）取别家长处、避开别家毛病。本文是方案，站长看过再做。

## 一、取长补短

| 别家做得好的（照学） | 别家的毛病（避开） |
|---|---|
| 规则卡：正面一条线索、背面规则 + 例词（Logic of English、拼读规则卡） | 生成器「印完就不管」，不记、不复习（Printmigo 自己写明） → 我们按拼音已有进度挑卡 |
| 对折卡：剪开对折就是正反面，不用对齐（Twinkl、Printmigo） | 双面打印要对齐、要测试页、要微调 → 只做对折，不做双面 |
| 洪恩：卡上的词句只用学过的字 | 内容和课本对不上 → 照 2024 统编一上 14 课排，例词用每课教学卡里站长审过的 |
| 家长卡 / 玩法（Kumon、四五快读） | 光给卡不给玩法，家长很快不用 → 每页纸底印一行玩法 |
| 一小撮难的混在会的里（Rocket Math 12 张里 3 张难、递增复习 1:8） | 一次印一大摞、全是新的 → 一页 6 张：本课 + 该复习的 |
| 打钩 / 分堆记熟练度（四五快读、Leitner） | 计时、快闪（多曼）制造压力、没证据 → 不计时、不快闪 |
| 拼音字体单层 a、g | 市售卡用英文字体，a、g 带尾巴 → 用站上已有的拼音字体 |
| — | 卡面字太多，一年级孩子读不了 → 正面只放孩子要认、要读、要写的东西（大号拼音），文字问题是家长念的；背面大号答案在上，口诀、例词、易错小字在下给家长看 |
| — | 下载 PDF 限次数、要会员（练学宝） → 直接浏览器打印，不限 |
| — | 网上流传盗版卡（洪恩 PDF） → 内容全部原创，口诀用通行的教学口诀 |

## 二、卡片长什么样

一张卡一个知识点，分正反两面：

正面（孩子看）
1. 上方一行小字：第几课 · 知识点名（如「第 6 课 · 小 ü 摘帽」）。
2. 中间大号拼音：要孩子认、读、写的东西（如「j + ü = ？」）。
3. 下方一行家长念的问题（如「ü 碰到 j，两点怎么办？」）。

背面（翻过来核对）
1. 大号答案（如「ju」）。
2. 口诀一行。
3. 例词一行（拼音 + 汉字）。
4. 易错一行（可省）。

## 三、内容：约 38 张，按 14 课排

每课 2–4 张，内容从每课教学卡（发音、口诀、易错、书写、例词）和专题里提炼。初稿：

| 课 | 卡 |
|---|---|
| 1 a o e | 三个口形（大、圆、扁）；四声手势（mā má mǎ mà） |
| 2 i u ü | u 和 ü 的嘴形；i 标调先去点（mí） |
| 3 b p m f | b / d 认形；b / p 认形；b / p 有没有气；两拼：前音轻短后音重（b + ā = bā） |
| 4 d t n l | n / l 捏鼻子试；d / t 有没有气 |
| 5 g k h | g 只有一个圈、别和 9 认混；三拼：声轻介快韵母响（g + u + ā = guā） |
| 6 j q x | j q x 不和 u 在一起；小 ü 摘帽（j + ü = ju）；ju qu xu 里的 u 读 ü |
| 7 z c s | zi ci si 整体认读，直接读不拼 |
| 8 zh ch sh r | 平舌、翘舌；zhi chi shi ri 整体认读 |
| 9 y w | 小 i 写成 yi、小 u 写成 wu；小 ü 写成 yu（u 读 ü） |
| 10 ai ei ui | 标调歌（有 a 不放过）；复韵母一口气滑过去 |
| 11 ao ou iu | iu、ui 标在后（liù、guì）；ao / ou 开头嘴形 |
| 12 ie üe er | ie / ei 认反；üe 去点（jue que xue yue）；er 不跟声母拼 |
| 13 an en in un ün | 前鼻音舌尖顶；ün 去点（jun qun xun yun）；yuan yin yun 整体认读 |
| 14 ang eng ing ong | 后鼻音舌根抬；前后鼻音成对读；ong 不单独成音节；ying 整体认读 |
| 总结 | 23 个声母；24 个韵母；16 个整体认读音节 |

内容是手写的，写完先出审阅稿 docs/review/pinyin-flashcards.md 给站长看（和 11-27 拼音教学卡一样走一遍）。

## 四、纸样

1. A4 纵向，一页 6 张（2 列 × 3 行），每格约 97 × 92 mm；中间一条虚线是对折线，上半正面、下半背面（倒过来印，折过去正好朝外）；外框实线是剪裁线。折好一张约 97 × 46 mm，比名片略大。
2. 另有「大卡」：一页 4 张，折好约 97 × 69 mm，接近手掌大小，适合小一点的孩子。
3. 页脚一行玩法：「剪下对折。家长念问题，孩子答完翻过来对。分三堆：会了、犹豫、不会；不会的明天再过，会了的一周过一次。」
4. 不做双面打印、不做测试页、不放图片（调研里加图对记忆帮助不明显，拼音靠口诀；也省掉图片版权）。

## 五、放在哪、怎么出

拼音页顶上的页签加一个「闪卡」：今日 / 专题 / 课程 / 闪卡 / 历史。

1. **按课印（默认）**：选「第几课」，一页 6 张 = 这一课的卡 + 前面课里拼音进度为「该练了」的知识点对应的卡，再不够用前面的卡补；默认选孩子正在学的那一课（今日卷的进度）。
2. **印整套**：38 张一次印完（约 7 页），剪好放盒子里，按三堆自己轮换。
3. 屏幕上能直接翻看每张卡（点一下翻面），不印也能用。

## 六、第一期不做的

1. **不打分**：拼音的「该练了 / 已掌握」是从孩子读、写拼音卷得来的；闪卡考的是规则记没记住，混进去会把进度弄乱。第一期只「读」进度来挑卡，不「写」进度；家里分三堆就是记录。用一阵子看家长要不要再接打分栏。
2. 不做识字、数学知识点闪卡（拼音试完再说）。
3. 不做读音（和教学卡一样）。

## 八、做法与验证

1. 数据：js/pinyin-cards.js，每张卡 { id, lesson, direction（对上拼音进度）, title, front: { big, ask }, back: { big, rhyme, words, pitfall } }。
2. 出卡：pinyin-core 加 pickCards(lesson, state)，纯函数，node 测；排版 pinyin-render 加 cardsSheet。
3. 检查：每张卡的 lesson、direction 存在；拼音只含合法拼音字母和调号；例词与该课教学卡例词一致或已学；每张卡在两种尺寸下都不溢出（浏览器里量）。
4. 先出 6 张样卡（第 6 课和第 10 课附近）+ 一页纸样给站长看，再写全套。
