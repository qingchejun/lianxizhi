# 识字「每日一卷」设计

日期：2026-11-09 · 状态：待用户确认

## 背景

识字字表 1600 字的一轮复习已走完（16 周 × 100 字/周），错字集摸清了底。日常使用改为
每天一卷：到期错字按记忆曲线复习 + 认识的字随机抽查。同时解决两个使用痛点：

1. **卷面会「变脸」**：打印识字卷后切去别的板块打印，再回来时附页错字重新抽了一批，
   和手里的纸对不上，没法登记孩子的真实表现。根因：板块间跳转是整页重新加载，
   附页那 20 个字（appendPick）只存在 JS 变量里，重开页面就重抽。
2. **标记语义分裂**：「本周复习」点不认识的字、「错字集」点认出来的字，两套方向相反的
   规则，容易点反。

## 目标

- 每天最多生成一卷；生成后字固定，直到登记（或作废）才出下一卷
- 统一全站标记规则：**点不认识的字**；「登记」时没点的算认出
- 错字按间隔阶梯复习，毕业（移出错字集）条件由累计错误次数 n 决定
- 老数据（错字集、复习记录、历史统计）无缝迁移

## 毕业阶梯（用户 2026-11-09 拍板）

- **间隔表**：进集后第 1 天考；认出一次后隔 3 天；之后 7 天、15 天
  （认出间隔序列 `1 → 3 → 7 → 15` 天）
- **毕业所需认出次数 K**：n = 1 时 K = 2；n ≥ 2 时 K = 4
  （n = 该字累计「没认出」次数，沿用现有 ×n 左上角标）
- 任一步没认出：k 归 0、n + 1，次日再考
- 毕业的字移出错字集，回到随机抽查池；以后抽查再错则重新进集
  （此时 n ≥ 2，自动走四步阶梯）
- 每日一卷的错字位：取到期（due ≤ 今天）的错字，最逾期优先、其次 n 大、
  再随机打散；最多 10 个。**不足 10 个不预支未来的**，缺额用认识的字补

## 每日一卷的生命周期

- 打开识字页默认进「每日一卷」页签
- 当天没有已生成的卷、且没有未登记的旧卷 → 自动生成
- 存在未登记的旧卷（如隔天没考完）→ 显示旧卷 + 提示先登记或「作废」；
  作废 = 直接删除该卷，字的数据不动（保持到期状态），当天可重新生成
- 一天（本地日期，沿用现有 `today()`）最多一卷；当天已登记 → 显示
  「今天已完成，明天见」+ 往期卷入口
- 卷子内容 = 10 个到期错字 + 随机认识的字补足 20；**生成后冻结**，
  切板块、关机重开都一样
- 认识的字从「不在错字集里的全部字表字」完全随机抽，不加权重、不排除最近出过的
- 打印沿用现有字格排版，标题带日期；纸上不印任何标记
- 归档保留最近 60 卷，可翻看

## 登记流程

1. 对照打印纸，点孩子没认出的字（红底标记；登记前再点一下 = 撤回）
2. 点「登记结果」：
   - 认识的字被点：进错字集（n = 1、k = 0、due = 明天）
   - 错字被点：k = 0、n + 1、due = 明天
   - 错字没被点：k + 1；若 k 达到 K → 毕业（记 out）；否则 due = 今天 + 间隔表[k]
   - 认识的字没被点：不变
3. 卷子归档；当天可「撤销登记」整卷回滚
4. 记一行复习记录（沿用 `sumsum:shizi:log:v1` 格式，seen = 卷上的错字）

## 老页签的语义统一（行为变化，上线时要跟用户说清）

- 「错字集」「本周复习」的点击统一为**点不认识的字**：
  以前错字集页点 = 认出一次，现在点 = 又没认出（k 归 0、n + 1）
- 「结算」统一为**没点的算认出**（原错字集页的结算含义正好对调）
- 「本周复习」保留可用（含附页），附页错字结算规则同上
- 「历史」页签不动；格子右上角数字 = 还差几次毕业，左上角 ×n 照旧

## 数据与迁移

- 新键 `sumsum:shizi:wrong:v3`：字 → `{ add, n, k, due, first, miss, out }`
  （out 存在 = 已毕业；k / due 仅在集内有效）
- 迁移（读 v2/v1，写 v3）：在集内无 hit → k = 0；有 hit → k = 1；
  due = 迁移当天（一轮刚结束，都当「到期」）；已移出的原样保留 out；n、first 照搬
- 新键 `sumsum:shizi:daily:v1`：`{ papers: [{ d, known, wrong, settled }] }`，留最近 60 卷
- 键前缀 `sumsum:` 不变（红线）；v2/v1 旧键不删（老备份仍可导入）
- 纯函数进 `shizi-core.js`（毕业步进、到期挑选、卷子构建、迁移映射），
  `tools/check-shizi.js` 先写测试再实现（TDD）

## 非目标

- 不改打印排版体系（sheet.css / layout）
- 不动字表与 TOTAL
- 不做「一天多卷」、不做补打过去的卷子
