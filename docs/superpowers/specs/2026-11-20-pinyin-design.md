# 拼音巩固板块 · 设计文档

日期：2026-11-20
状态：待站长审定
需求来源：站长口述 + GPT 提示词底稿（2026-11-20），以本文档为准

## 1. 背景与目标

孩子 6 岁、一年级，学校拼音已教完：拼音表能读（及格水平），但个别字母混淆
（b/d/p/q，具体混哪一对、单认还是拼读时混，尚不确定），部分词语拼不出。

目标：**每天 5–10 分钟（学习 + 练习合计）小步快跑**，按 5 分钟配卷，
练到哪算哪，不欠账。核心是「先检验、再决定教什么」——不从一次错题推断整类能力。

非目标（首版不做）：

- 音频播放（无可靠授权音源；示范词由家长读，读音由家长耳朵判断）
- 任何账号 / 权限 / 支付相关改动
- 其他板块的改动（首页接入除外，见 §10）

## 2. 术语

| 术语 | 含义 |
|---|---|
| 方向 | 一个可观察、可判定的最小技能点，如「b/d 字形认读」「两拼 b+ā」。引擎调度的单位 |
| 对照 | 方向所属的混淆对（b/d、n/l、an/ang…） |
| 组 | 卷上的一段同类题目，通常 4–6 题 |
| 卷 | 某一天完整的练习：基础认读、应用、按需复习或观察，以及条件检验和纸尾教学卡 |
| 教学 | 卡住时给家长看的内容：一句怎么讲 + 一个示范 + 2–3 项引导 |
| 检验 | 用没有原样示范过的同难度新题再试，当场跟读对与独立读对分开记 |
| 登记 | 家长对某题的结果记录 |

拼音板块**从零新建**（全库无拼音实现）。可复用的骨架：

| 复用 | 说明 |
|---|---|
| 板块文件模式 | `pinyin.html` + `js/pinyin-core.js`（纯逻辑，node 可测）+ `js/pinyin-data.js`（题库数据）+ `js/pinyin-main.js`（DOM 编排）+ `js/pinyin-render.js`（屏幕渲染）|

| 参考实现 | 识字板块的「每日一卷 + 错字两步毕业」机制（状态机与复核思路同源） |

## 4. 每日练习（卷）的结构

### 4.1 卷面与练习路径

一天只设一个教学重点。以首次 b/d/p/q 观察卷为例，孩子区和家长区按以下方式配合：

| 组 | 纸上内容示例 | 什么时候做 |
|---|---|---|
| 1　读字母 | d、p、b、q，顺序打乱 | 先独立读，记录具体卡在哪个字母 |
| 2　拼一拼 | bā、dī | 第 1 组顺利时仍做这两题，观察放进音节后能否读出 |
| 3　复习 | 到期方向各 1–2 题 | 有到期项才印，计入当日题量 |
| 4　试一试 | 未观察方向 1–2 题 | 有余量才做，只收集表现 |
| 5　换题再试 | 与今天重点对应的两道独立检验题。首次字形分支列出四个备选字母，由家长挑两个复核 | 第 1、2 组卡住时，按家长卡对应分支练完再做 |

家长卡按「卡在认字母 / 卡在读音节」各给一句怎么讲、一个示范和对应的检验题号。一次只选一条分支。原因还不清楚时，先用一道更简单的题观察（如单认刚才音节中的声母），再决定是否示范。纸上列出两条分支，屏幕只展开选中的一条。读音节的检验须换未示范过的音节，孩子面隐藏提示、汉字和图片。

- **顺利时**：做完基础认读与应用，再做到期复习；有余量可试新方向，随后收工。
- **卡住时**：已有足够信息就停下当前组，转入一个小教学、两道新题检验，随后可以收工。复习、观察及另一条分支保持未练。
- 其他专题按能力选题。例如书写规则使用书写任务，登记时与口头表现分开。

### 4.2 固定当天卷

首次出卷用日期、当时的练习记录和选定重点生成题单，随即按日期存档。刷新、继续练、打印和补登记均读取原卷；换设备须先同步原卷。纸面标日期和卷号，跨天可按卷号找回。题库更新后仍须能显示原题。

手选专题或课程可以作为当天首次出卷的重点。当天已有卷时，手选练习另存一份记录，占用同一天的练习名额，保留原纸卷的补登入口。同一天多练不增加毕业天数。

### 4.3 量控

按实际走的一条路径配约 5 分钟，含教学、引导与条件检验，每条路径至多 15 题。先预留卡住时教学和换题的时间，再分配观察题；复习较多时先减新题。用真实家庭试练校准题量。随时可停，不计时、不补课。

## 5. 每日引擎（推荐规则）

1. 首次使用出 b/d/p/q 观察卷。之后有到期项就选最早到期的方向为重点；无到期项时按课程顺序选未观察方向。复习与可选观察题须服从 §4.3 的预算。
2. 按任务分别记录字形认读、音节拼读、声调及书写表现。看见 b 没读出，只记本次认 b 卡住；明确读成 d，才记录 b→d。读错 bā 而原因不明，只安排进一步观察。应用组一次失误不直接触发整类重教。
3. 提示过或没读出的方向次日可复核。教学后的独立检验单独记录：帮助家长判断今天能否收工，另日再确认掌握程度。跟读和引导练习不参与毕业。
4. 一次通过需在提示前独立做完该方向预设的复核题，至少两题且全对。认读混淆对须覆盖两边，另日打乱顺序；音节与词语另日须换实际例子。单道观察题、半组或同日重复登记均不足以算通过。首次通过后隔两天到期，两个不同日期均通过才稳固。
5. 稳固方向在手选练习中再次需要提示或没读出时，重新安排次日复核。有待复核方向但尚未到期、且无未观察方向时，或全部已稳固时，首页显示「今天可以休息」，仍可手选练习。

推荐写出家长能核对的事实，如「昨天 b、d 单独都读对了，读 bā 时需要提示，今天换两个音节再试」。

## 6. 方向注册表与内容

### 6.1 方向（引擎调度单位）

按十大类组织，首版全部可用（不只 b/d/p/q）。每类含需求列出的全部对照：

| 类 | 对照组 |
|---|---|
| 字形看混 | b/d、b/p、d/q、p/q（合并为一张四字母观察卷）、m/n、f/t、u/ü |
| 相近声母 | n/l、z/zh、c/ch、s/sh、b/p、d/t、g/k（送气对照）|
| 复韵母 | ai/ei、ao/ou、ie/ei、iu/ui |
| 鼻韵母 | an/ang、en/eng、in/ing |
| 声调 | 四声打乱、二声/三声对照、同音节换调 |
| 两拼 | 声母 + 韵母拼合（认得字母但拼不出的一步）|
| 三拼 | 声母 + 介音 + 韵母（guā、huǒ 类，观察漏介音在哪一步）|
| 整体认读 | z/zi、zh/zhi 等 16 个整体认读音节 vs 声母 |
| 书写规则 | 标调位置、i 加调去点、ü 省写、y/w 形式（与口头能力分开记）|
| 词句应用 | 熟悉双音节词起步 → 短句；读完可说意思 |

每个方向一条记录：`{ id, 类别, label, 出题参数, 教学(tip/示范/引导), 检验参数, 任务类型, 通过所需的题目与覆盖范围 }`。

### 6.2 二十课课程目录（照一年级教材顺序起草，可调）

① a o e　② i u ü　③ b p m f　④ d t n l　⑤ g k h　⑥ j q x（ü 去点）
⑦ z c s　⑧ zh ch sh r　⑨ y w　⑩ ai ei ui　⑪ ao ou iu　⑫ ie üe er
⑬ an en in　⑭ ang eng ing ong　⑮ 整体认读·上　⑯ 整体认读·下
⑰ 声调与标调　⑱ 三拼与介音　⑲ 拼写规则汇总　⑳ 词句应用 + 阶段复核

- 课程目录**全部开放**：可跳课、可回看、可分多天用；有基础的孩子从检验或词语应用进入
- 每课结构 = 讲解示例 + 2–3 项引导练习 + 独立检验（与卷的组结构同源）
- 课程与专题**共用**同一套方向注册表与题库；课程是「按大纲顺序的编排」，专题是
  「按家长观察到的问题的编排」

### 6.3 数据层

- **合法音节总表**：按小学教材口径构建（23 声母 × 韵母的合法搭配，约 400 基本音节），
  配校验器：每个音节可唯一拆分、不出教材外的怪音节
- **常用双音节词库**：一年级识字范围内的常用词，带拼音与汉字两个字段；
  检验时隐藏汉字。首版 200–300 词
- **题目变体**：每个方向至少 3 套等价变体（确定性轮换用）

## 7. 屏幕交互

- **孩子面**：只有编号和题目（大字号，无提示、无汉字、无图片）
- **家长区**：每组的目的、判定口径、跳组指引（「第 1 组能独立读，就跳到第 3 组」）
- **登记**：每题可点〔提示了〕〔没读出〕，再选填「读成什么」「声调错了」或自由文本。只填有把握的观察，留空即可。跟读、引导和独立题分别标记。
- **确认练到哪**：「本组做完」确认该组已练；中途收工或转教学时，点选最后做到的题号；整组跳过直接保留未练。组内跳过的题可点「未练」。只在确认的已练范围内，才把无异常标记的独立题记为独立完成。提前关闭页面保留已点的标记，空白题仍待确认。
- **撤销与补登**：更正题目结果或已练范围后，按修正后的记录重新计算通过次数和到期日。纸上顺的题不用标，提示画 ∨，没读出画 ×，中途停止圈最后一题，组内跳题画横线。跨天补登归入卷上练习日期。

- **目录**：课程（20 课）与专题（10 类）两个入口，全部随点随练；练完登记进同一套方向记录

## 8. 打印版式

- A4 纵向一张：上部孩子面（大字、编号），纸尾灰框家长区（跳组指引、该方向的
  教学提示、记号说明）——教学卡**预先印好**，纸上同样支持按表现跳组
- 打印预览 / 确认流程照现有 `#print` 机制
- 版式细节（字号、留白）沿用识字板块的一年级标准

## 9. 存储与恢复

- 每卷使用独立的 `sumsum:pinyin:sheet:v1:<日期>:<卷号>` 键。保存日期、重点、题库版本、题目顺序和稳定题号、方向与任务类型、展示内容及家长卡快照。同日重复打开复用已有日卷。两台设备离线分别开卷时各自生成唯一卷号，同步后保留两份，纸上卷号始终可定位。
- 每题登记按卷号和题号独立存储，包含练习日期、是否实际练过、结果、可选错因与练习阶段。确认范围只更新本次涉及的题；撤销写回修正结果。同一题跨设备修改沿用现有按键时间戳合并。重复保存同一结果只计一次。
- 方向状态、通过日期、下次复核和首页进度从有效登记推导。跨日补登、撤销、同步及备份恢复后按练习日期重算。字号等偏好单独保存在 `sumsum:pinyin:settings:v1`。所有写入走 store.js。

## 10. 首页接入（站长已拍板）

- 左侧导航加「拼音」一项（rail-link，照现有样式）
- 「今天」加第五张卡片：今天的方向、组数、练习进度、打印入口；休息日显示休息提示和手选入口
- 首页 meta description「四个板块」→「五个板块」
- 板块页 noindex 与否：拼音页**参与收录**（公开练习工具页，与口算/识字一致）

## 11. 验收场景

| # | 场景 | 验证方式 |
|---|---|---|
| 1 | 拼音表能读、今天四个字母和新音节都独立读出 → 几分钟收工，次日换未观察方向 | 引擎测试 + 走查 |
| 2 | 只混 b/d → 安排该对照小教学 + 新音节复核；p/q 保留各自真实记录 | 引擎测试 |
| 3 | 字母准、能拼、声调常错 → 直接练声调，不送回第一课 | 引擎测试 |
| 4 | 只练半页 → 保存/刷新/撤销/恢复后未练仍是未练；次日复习计入当日总量 | 引擎测试 + 走查 |
| 5 | 首页进入 → 打印 → 登记 → 看到下次建议，全程无需家长配题 | 走查 |
| 6 | 交付演示：一份真实 5 分钟练习走完上述流程 + 打印验证 | 交付物 |
| 7 | 上午打印，半组停下，晚上另一台设备同步后按卷号补登 → 题号与纸面一致，未练题不算对，次日推荐能追溯到该题 | 两设备走查 |
| 8 | b 未读出且未填错因 → 只安排认读观察；明确把 b 读成 d → 可安排针对性对照 | 引擎测试 |
| 9 | 同日重复、教学后跟读、单题观察均不毕业；两日符合 §5 的独立复核后稳固；之后手选练习失误可重新到期 | 引擎测试 |
| 10 | 更正误记或恢复备份后，到期日与有效登记一致；所有方向稳固时显示休息日 | 引擎测试 + 恢复走查 |
| 11 | 分别走顺利与卡住两条路径，记录含教学的实际用时；最长家长卡与两条检验分支在 A4 一页可读 | 家庭试练 + 打印验证 |
