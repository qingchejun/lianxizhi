# 练习闭环：出纸 → 打分 → 巩固 设计稿（2026-11-27 站长确认）

范围：练习四板块（口算、奥数、识字、拼音）。摸底、学习计划以后再做（站长 11-27 定）。
游戏五板块（数独、火柴、密码、迷宫、数织）不再打分。

## 0. 现状（2026-11-27 读代码）

| 板块 | 打分方式 | 打分后怎么影响出题 | 问题 |
|---|---|---|---|
| 口算 | 会了/一般/不会，可展开点错题（mark 页） | `kousuanNext`：只看「最近一次打分、之后没再打印」的那张，错题最多 5 道原样进下一张 | 打印下一张后错题就丢了；没有「对了再复查」 |
| 奥数 | 每课三档 + 点错题 | 写 learned / review-due；今天页只推「下一课」，待复习要家长另点「打印复习卷」 | 没选到的课不会自动回来 |
| 识字 | 点没认出的字 → 登记结果 | 错字集 v3 + 每日一卷（明天考、隔 3 天复核、认出 2 次毕业） | 规则不动；只改打分手感（没有「全认识」一键） |
| 拼音 | 拼音页逐组逐题：顺/提示了/没读出/跳过/停在哪题 | `derive` 按方向（direction）算 due，复习组自动进卷 | 闭环已有，打分太繁琐 |
| 游戏 | 太简单/刚好/太难 → 自动升降关 | — | 站长定：不打分 |

打分入口：纸角二维码 → `/mark?id=`；页面上半是这张，下半是「今天和昨天打印、没打分的全部纸」混在一起。电脑顶栏「登记」按钮也进这一页。
更早没打的纸静默消失，家长不知道。

数据：全部在浏览器 localStorage（`sumsum:*`），登录后按键同步到 D1 `data(user_id, key, value, updated_at)`，每键整值、新者胜。
纸记录 `sumsum:sheet:v1:<id>` 一纸一键，60 天清理。

## 1. 打分（第一期）

### 1.1 统一规则：全对，或者点错题（站长 11-27 定）
每张纸只有两条路，四个板块一样：

```
（题目格子直接摊开：口算印算式，奥数印「第 n 题」，识字印字，拼音印音节/字母）
[ 全对 ]                       ← 选择项，和「点错题」二选一
[ 提交 ]                       ← 唯一的提交按钮；什么都没选时是灰的
```

1. 先选：点「全对」，或者在格子里点错的题（两者互斥：点了错题，「全对」自动取消；再点「全对」，错题清空）。
2. 再点「提交」才算数。全对和有错走的是同一个「提交」，只有这一个按钮，误点「全对」也能在提交前改。
3. 不再有：会了/一般/不会、展开、这张没做、提示了/没读出/读成了什么/声调错、停在哪题。
   奥数「这课学会没有」仍在后台按错题比例自动算（沿用 `levelFromWrong`），家长看不到档位。
4. 没做的纸就不打，2 天后自动不催（1.3），不用专门点「没做」。
5. 识字「全对」= 全认识，背后仍走 shiziMark.settle（规则不动）。
6. 拼音：格子按纸上的组排。「换题再试」组只在它对应的那组点了错题时才算做过（卡住才做），否则记没做；
   「试一试」组只有点了错题才记，没点记没做（不当作全对，免得没做也被当成会了）。
   点错 = 记 miss；原来「读成了什么 / 声调错」两条细分的作用（把错误归到形近字母组、声调组）放弃，换取一步打完。
   `derive` 输入格式不变。

### 1.2 每个板块单独打，电脑手机都能打
1. 四个练习板块页面右侧加「打分」页签（拼音已有登记区，改成同一套卡片）：上面是「待打分」，下面是「历史」（60 天内打印过的纸，按日期，可补打、可改）。
2. 扫码页 `/mark?id=` 只显示扫的这一张；下面一行小字「口算还有 1 张没打分」，点了去口算页的打分页签。不再把所有板块混在一起。
3. 今天页的「还有 N 张没打分」按板块分开写。

### 1.3 不累积
1. 「待打分」按板块分开，只列**打印后 2 天内**还没打分的纸（同一天打了两张口算就列两张）。
   超过 2 天没打 → 进历史里的「没打分」，不催、不计数、不算对错。
2. 打印预览、重印不产生新纸（纸号按内容算，现状如此）；只有点过打印的才算一张。
3. 历史里随时可以补打、改打；补打的结果照样进巩固池（第 2 节）。
4. 识字每日一卷自己有「往日欠账」机制（卷子冻住、按日期连考），不受这条影响，照旧。

### 1.4 游戏去掉打分
游戏纸不再印二维码、不进待打分、不自动升降关；今天页的「按上次反馈加难/降难 + 撤销」去掉。已经自动改过的难度保持现状。

### 1.5 细节
1. 点错题的半成品要存在本机（像识字的 picks），手机锁屏、切走再回来不丢；「提交」才算数。
2. 提交后卡片变成「已打分：全对」或「已打分：错 3 题」+「改一下」。改完以最后一次为准，后续出题跟着重算。
3. 格子里的题号/题面和纸上印的一致（口算显示算式，避免家长数题号数错；奥数显示题号，纸上题号要醒目）。
4. 题多的纸（口算 60–100 题）手机上按纸的行排，一屏能看完一大半，不做分页。
5. 打分页面不出现「档位」「等级」这类词，只说「全对」「错了几题」「明天会再出哪几题」。

## 2. 打分之后：巩固池 + 每天的纸留巩固位（第二期）

### 2.1 统一的节奏（照识字）
每个板块一个「巩固池」，每项的生命周期和识字一样，家长只需理解一套：

```
错 → 明天的纸上再出 → 对了 → 隔 3 天复查 → 又对了 → 过关
                  ↘ 错了：回到「明天再出」（错的次数累计）
过关后再错 → 重新进池
```

识字本身规则不动（它就是这套）。拼音现有 `derive` 节奏是「错→明天；过→2 天后换题确认；连过 2 次稳固」，与此接近，**不改**。

### 2.2 每个板块「错的是什么」
| 板块 | 进池的单位 | 巩固位出什么 | 每张纸巩固位 |
|---|---|---|---|
| 口算 | 错的那道算式（如 13−8） | 到期算式原题混进当天的纸；同一类（进位加/退位减/乘/除…）错 ≥3 道时当天整张偏这一类（沿用 carrymore 思路） | 最多 5 道 |
| 奥数 | 错题所在的**课** | 当天的纸后面加「巩固」小节：从到期的课各出 1 道新题（换种子，不是原题） | 最多 2 课 × 1 道 |
| 识字 | 字 | 不变（每日一卷 ≤10 个错字位） | 不变 |
| 拼音 | 方向（声母、整体认读…）| 不变（复习组） | 不变 |

回答站长「奥数没选到那个知识点会不会出」：现在不会；改后不管家长选哪一课、出的是哪张，只要有到期的课，纸的末尾都会带上巩固题，不用家长去选。
原来的「待复习满 3 课 → 打印复习卷」保留为可选。

### 2.3 数据：从打分记录推算，不另存可变状态
1. 巩固池不单独存一个「池子」键，而是每次出纸时从该板块全部纸记录（`sumsum:sheet:v1:*`，一纸一键）**推算**出来——和拼音 `derive` 同一个做法。
   好处：手机打分、电脑出纸同时发生也不会互相覆盖（同步是每键新者胜，单一池子键会丢更新）；改分、撤销不用写「撤回」逻辑，重新推算即可。
2. 判断「对了」：巩固题印在纸上时记进纸记录（item 带 `review: <池子项>`），这张纸打分时没点它 = 对。
3. 纸记录 60 天清理会丢掉更早的证据。到期项每天都会上纸，60 天内一定有新记录，影响很小；以后做摸底/学情需要长期数据时，再加每月一份压缩快照（不在本期）。
4. 识字维持自己的 `wrong:v3`（规则不动）。
5. 印了巩固题但整张纸没打分：这些题不算对也不算错，第二天照样到期再出，不会因为没打分就「过关」。
6. 巩固题在纸上不另做标记（孩子不需要知道哪几道是旧错题，口算混在中间，奥数放在末尾「再练一练」小标题下）；打分格子里给家长标一个小「巩固」字样。
7. 口算换了练习范围（比如从加减换到乘法），池子里的加减错题照样带，仍然最多 5 道。

### 2.4 让家长看得见
每个板块打分页签里加「巩固」小块：在练 N 个 · 待复查 N 个 · 已过关 N 个，点开看清单（识字已有错字集页面，照它的样子）。
今天页每张卡片写「含 N 道巩固题」。

## 2.5 站长 11-27 定
1. 口算、奥数用识字节奏（2.1）。
2. 巩固位数量同意，但**总题量不变**：巩固题占用当天题量，不额外加题。口算默认 20 道（含最多 5 道巩固），奥数默认 5 道（含最多 2 道巩固）。
3. 待打分只催打印后 2 天内的纸。
4. 先做第一期，用一阵再做第二期。
