# 拼音板块屏幕页改版 · 给 Claude Design 的需求说明

日期：2026-11-21
用途：站长把本文贴给 Claude Design 出稿；定稿后由 Claude Code 落到代码。**纸卷（打印出来的那张 A4）不在本次改版范围内**，已于 2026-11-21 单独定稿。

## 1. 背景

练习纸（lianxizhi.qingchejun.com）是给一年级孩子打印 A4 练习纸的网站。家长在**电脑上**设置、打印，孩子在纸上做，家长再回到电脑上登记结果。手机只要能打开、不塌即可，不必为手机设计。

整站已有统一的「工作台」骨架（2026-10-04 Claude Design 定稿，链接：https://claude.ai/artifact/2oLftxEEiKVL25rNvko5fj ）：

- 左侧深色板块栏（今天 / 口算 / 奥数 / 识字 / 拼音 / 数独 / 密码 / 数织 / 迷宫，底部说明 / 账号 / 备份）
- 顶栏：板块名 + 一行灰色摘要（如「每日一卷 · 认识 20 · 11/21 · 共 1 页」）+ 右上角蓝色「打印」按钮
- 中间：纸张预览区，**屏幕上看到的纸 = 打印出来的纸**
- 右侧：设置面板，顶部一排分段标签（识字是「每日一卷 / 本周复习 / 错字集 / 历史」），下面是分区卡片

拼音板块是新加的，**没有照这套骨架做**，是本次要解决的问题。识字板块是最接近的参照（同样是「每日一卷 + 登记结果」）。

## 2. 现在的问题（请对照截图）

1. 中间放的是一张很长的登记表，纸卷要点「查看纸卷」才在下方出现，违背「看到的就是打印的」。
2. 「今日练习 / 专题 / 课程 / 历史卷与补登」做成了四个普通按钮，和其他按钮长得一样。
3. 屏幕上有四排外观相同的按钮（入口、查看纸卷 + 字号、分组、孩子视图），家长看不出「现在做到第几组」。
4. 每道题的登记要先点开「第 N 题登记 · 待确认」折叠框，再点结果，一张 14 题的卷要点几十下。
5. 「题目字号」是浏览器原生下拉框，其他板块用的是分段按钮。

## 3. 要设计的页面

### 3.1 今日练习（默认页）

- **中间**：A4 纸卷预览（现成，直接放）。
- **顶栏摘要**：今日重点 + 组数 + 进度，例如「观察 b、d、p、q · 5 组 · 已练 2 组」。
- **右侧面板**：
  - 顶部分段标签：今日 / 专题 / 课程 / 历史
  - 「为什么练这个」一句话（例：「昨天 b、d 单独都读对了，读 bā 时需要提示，今天换两个音节再试」）
  - **分组进度**：第 1 组 → 第 2 组 → … 竖排或横排步骤条，每组显示名称和状态（未练 / 已记 3/4 / 做完）。「换题再试」「试一试」两类组要和正常组区分（它们只在卡住或有余量时才做）。当前组高亮。
  - **当前组登记区**：每题一行：题号 + 题目（大字、拼音字体）+ 三个小按钮〔提示了〕〔没读出〕〔跳过〕。顺的题什么都不点。点了〔提示了〕或〔没读出〕后，这一行展开一个小输入框「读成什么」，读音题再加一个「是声调错」勾选。
  - 组底部：主按钮「本组做完」；次要操作「做到一半就停了（选最后一题）」；卡住时出现「转教学，换题再试」。
  - 给家长的教学卡（怎么讲 / 示范 / 引导 ①②），在当前组卡住时出现，平时折叠。
  - 「孩子视图」：把当前组的题以超大字号全屏或大卡片显示给孩子看（屏幕上直接练，不打印时用）。
  - 题目字号：分段按钮 26 / 32 / 40。
- 所有组做完后：右侧显示「已保存」+「下次建议：……」。

### 3.2 专题 / 课程

- 专题：10 类（字形看混、相近声母、复韵母、鼻韵母、声调、两拼、三拼、整体认读、书写规则、词句应用），每类 1–8 个可点的练习项。
- 课程：20 课，每课 1–3 个练习项。
- 现在是中间一长条列表。请设计成放在**右侧面板**里的目录（或中间区域的目录卡），点一项 → 中间出现该项的纸卷，右侧切到登记区。希望能标出每项状态：没练过 / 待复核（附日期）/ 已稳固。

### 3.3 历史

- 按日期列出已出过的卷：日期、卷号、重点、进度（已练几组）。点开 → 回到 3.1 的布局，可以补登记。
- 家长靠纸上印的卷号找卷，卷号要醒目。

### 3.4 首页「今天」的拼音卡片

已有，保持风格一致即可；如设计上有更好的缩略图画法可一并给出。

## 4. 硬约束

- 纸卷内容和排版不改（已定稿）；屏幕预览里的纸就是一张 210mm 宽的白纸。
- 不用 Google Fonts（国内打不开）。拼音题目用站内自带的「Pinyin Kids」字体（单层 ɑ、ɡ，和课本一致），界面文字沿用现有字体，**body 的字体和行高不能改**（其他板块的纸卷继承它）。
- 颜色沿用现有变量：`--blue #2a55c9` 可操作/选中，`--red` 错，`--green` 已学。不用渐变背景、emoji 装饰、左侧彩色边框卡片。
- 左侧板块栏和顶栏是全站共用的，不重新设计。
- 桌面 1280–1600px 宽为主；≤900px 时整页滚动、面板排到纸下方即可。

## 5. 需要的产出

1. 今日练习：未开始 / 做到一半有题卡住 / 全部做完 三个状态。
2. 专题目录、课程目录、历史列表各一屏。
3. 孩子视图一屏。

## 6. 落代码时 Claude Code 一并做的逻辑改动（不需要设计）

- 卷号由 12 位乱码缩短为「日期 + 短码」（如 1121-A7），仍保证两台设备离线各自出卷不撞号。
- 使用说明里拼音的排序和左侧栏一致（排在识字后面）。
