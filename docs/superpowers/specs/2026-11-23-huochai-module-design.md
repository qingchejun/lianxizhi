# 火柴棒算式板块设计（huochai）

日期：2026-11-23 · 状态：站长已在聊天里批准设计稿（「可以」）

## 0. 为什么做它

2026-11-23 三路调研（成都四川学校活动、全国一二年级比赛与童书、北师大课本与家长圈）
的结论：原定的「数谜（Kakuro）」在一二年级零证据，撤下；火柴棒算式在全国一二年级
比赛里出现最多（厦门低年段「巧移火柴棒」、上海一二年级挑战赛、武汉二年级），
练口算、规则一句话讲得清、画成火柴图能打印。游戏组排序按受欢迎程度：
数独 → **火柴** → 密码 → 迷宫 → 数织。

## 1. 玩法

卷子上印一道用火柴拼出来的**错的**算式，按提示**拿走 / 添上 / 移动一根**火柴，
让算式成立。

- 数字按七段（电子表）拼法，每段一根火柴；`+` 两根（横、竖），`−` 一根（横）；
  `=` 两根，**不许动**（不参与任何改法）
- 七段字形（段名 a 上、b 右上、c 右下、d 下、e 左下、f 左上、g 中）：
  0=abcdef 1=bc 2=abdeg 3=abcdg 4=bcfg 5=acdfg 6=acdefg 7=abc 8=abcdefg 9=abcdfg
  （6 带 a 顶、9 带 d 底、7 为三根——与常见火柴题一致）
- 改动可以落在数字上，也可以落在运算符上（`−` 添竖变 `+`、`+` 拿竖变 `−`）
- 「移动」= 拿走一根再放到另一个位置（可在同一个符号内，如 6→9；也可跨符号）；
  放回原位不算
- 不能凭空多出新符号（不在空白处新拼一个数字），也不能把一个符号拿空

孩子在原图上作答：拿走的那根打 ×，添上的那根用铅笔画出来，再把改好的算式
用普通数字写在下面的横线上。

## 2. 关卡

| 关 | 名字 | 改法 | 数的范围 | 能出的题（11-23 穷举试算） |
|----|------|------|----------|------|
| L1 | 拿走一根 | 拿走一根 | 0–9 | 255 |
| L2 | 添上一根 | 添上一根 | 0–9 | 203 |
| L3 | 挪一挪 | 移动一根 | 0–9 | 483 |
| L4 | 两位数挑战 | 移动一根 | 0–20，原式或答案至少有一个两位数 | 1705 |

试算数字是加上红线前的上限；加了 §4 的「0 的限制」后会少一些，实现时校验器
报出每关实际题数，任何一关少于 60 道要回来跟站长商量。

## 3. 生成算法（huochai-core.js，无 DOM 依赖）

题少、范围小，**不随机构造，而是穷举**：

1. 枚举本关范围内全部 `A op B = C`（op ∈ {+, −}，A、B、C 在范围内）
2. 跳过本来就成立的式子（原式必须是错的）
3. 对每条错式，按本关改法把所有单根改动都试一遍，解析成算式、检查成立，
   收集「改对后的算式」集合
4. 集合**恰好 1 个**且满足 §4 全部约束 → 进题池；同时记下动了哪一根
   （答案页要标）。同一结果有多种动法时取任一种标注（结果唯一即可）
5. 题池按关缓存；出卷 = 用种子随机数从题池里抽 `count` 道，同卷不重复
6. 题目对象：`{ level, kind, from: {a, op, b, c}, to: {a, op, b, c}, edit }`，
   `edit` 描述被拿走 / 添上的那根（符号序号 + 段名）

随机数沿用迷宫加固过的 makeRandom（种子先搅一遍），同种子出同卷，网址可复现。

## 4. 质量红线

1. **唯一答案**：每道题改对的结果恰好一个（§3 第 4 步穷举保证）
2. **原式是错的**
3. **答案在范围内**：改完后的 A、B、C 都在本关范围内，减法结果不为负
4. **不出怪数**：不出 `08` 这种以 0 开头的两位数；原式和答案里数值 0 各最多出现
   一次（避免 `0+0=8` 这种题）
5. **同卷不重复**（按原式去重）
6. **独立校验器** `tools/check-huochai.js`：另写一套七段表和改动枚举（不 require
   core 的内部实现），对每关题池逐题复核 1–5，并用大量种子出卷检查不重复、
   数量正确；全部通过才上线

## 5. 卷面

- 黑白，A4 纵向，每页约 5 道（排版时定，L4 算式长按版心宽度定火柴尺寸）
- 卷面顶部规则行：「第 N 关 · 名字 —— 按提示动一根火柴，让算式变对」
- 每道：题号 + 改法标签（拿走一根 / 添上一根 / 移动一根）+ 火柴算式（SVG 画，
  火柴带火柴头）+ 下面一条横线写改好的算式
- L2–L4 在每个数字的空段位置印淡虚线，提示火柴能放在哪；运算符位置的竖段空位
  同样印虚线（`−` 能添成 `+`）。L1 不印
- 答案页：正确算式（普通数字）+ 原图上标出动的那根（拿走的画 ×，添上的画粗实线）；
  每页题数多于卷面，缩印

## 6. 设置

与其他板块一致（套路同 mima / migong）：关卡（L1–L4，默认 L1）、题量（1–10，
默认 5）、打印份数（默认 2 同题对战）、打印时附答案页（默认关）、标题（选填）；
写进 localStorage 和网址，「重新生成」换一批。

## 7. 接入与文件清单

- `js/huochai-core.js` 七段表、改动枚举、题池、出卷
- `js/huochai-settings.js` 设置（默认值 / 钳位 / localStorage / URL）
- `js/huochai-render.js` 卷面与答案页渲染（buildHTML 纯字符串，node 可测）
- `js/huochai-main.js` 页面交互
- `css/huochai.css` 卷面样式
- `huochai.html` 页面（骨架同 migong.html）
- `tools/check-huochai.js` 独立校验器
- `tools/rail.py` 游戏组第二位加「火柴」，重跑生成全部页面侧栏
- `js/today-core.js` / `js/today.js` 游戏卡片第二位加火柴（含卡片小图）；
  `tools/check-today.js` 跟着改
- `js/help.js` 加「火柴」页签（排数独后）
- `js/changelog.js` 更新记录加一条

## 8. 第一版不做

在线玩（以后像数织那样单独加）；移动两根；乘除法。
