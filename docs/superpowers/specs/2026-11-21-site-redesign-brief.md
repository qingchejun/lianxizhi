# 「练习纸」全站视觉升级 · 设计需求

请为一个给小学一年级孩子打印练习纸的中文网站做一次全站视觉升级。目标：**看起来像一个正规、可信的产品**，而不是个人做的小工具。网站马上要分享给同班几位家长使用。

线上地址（可以直接打开看现状）：https://lianxizhi.qingchejun.com
上一次的整站设计稿（骨架沿用它，这次是在此基础上提升质感）：https://claude.ai/artifact/2oLftxEEiKVL25rNvko5fj

---

## 一、产品是什么

- 名称：**练习纸**（品牌名不改）。
- 使用方式：家长在**电脑**上选好题型，打印 A4 纸给孩子做，做完回到电脑上登记对错，网站据此安排下一天的练习。
- 用户：同班几位家长，一年级孩子（6 岁）。需要邀请码才能注册。
- 板块（共 9 个）：
  - 练习类：**今天**（首页，汇总各板块今天该练什么）、**口算**、**奥数**、**识字**、**拼音**
  - 游戏类：**数独**、**密码**（逻辑推理猜密码）、**数织**（涂格子画画）、**迷宫**（口算迷宫）

## 二、现在的问题

1. 整体太朴素，像内部工具：没有品牌标识，各页面质感平淡，看不出是一个正式产品。
2. **图标很业余**：
   - 浏览器标签页图标用的是表情符号（奥数 🧠、密码 🔐、其他 ✏️，拼音页没有），每页不统一。
   - 没有手机桌面 / 收藏夹图标。
   - 左侧板块栏的图标是随手画的线条图标，粗细和风格不统一。
3. 没有登录页、没有介绍，朋友第一次打开不知道这是什么网站。
4. 拼音板块没有按全站骨架做（详见第四节第 5 条）。
5. 没有页脚。

## 三、保留不动的骨架（在此基础上提升质感）

- 左侧深色**板块栏**：练习组（今天 / 口算 / 奥数 / 识字 / 拼音）、游戏组（数独 / 密码 / 数织 / 迷宫），底部是说明 / 账号 / 备份。
- **顶栏**：板块名 + 一行灰色摘要（如「每日一卷 · 认识 20 · 11/21 · 共 1 页」）+ 右上角主按钮「打印」。
- **中间**：A4 纸张预览，屏幕上看到的纸就是打印出来的纸。
- **右侧**：设置面板，顶部可有分段标签，下面是分区卡片。

## 四、需要设计的内容

### 1. 品牌标识与图标（一整套，风格统一）

- 「练习纸」标识：图形 + 字标，用在板块栏顶部、登录页。
- 浏览器标签页图标（全站统一一个，16px 下也要清楚）。
- 手机桌面 / 收藏夹图标（180×180）。
- 9 个板块图标 + 说明 / 账号 / 备份 3 个功能图标，同一套线条粗细和圆角，深色栏上清晰。
- 请交付 **SVG 源码**。

### 2. 登录与注册（新页面，最重要）

网站将改为**必须登录才能使用**，没登录的人打开任何网址都只能看到这一页。

- 页面要说明白「练习纸是什么」：一两句介绍，配几张练习纸缩略图或板块示意，让第一次来的家长有信任感。
- 表单流程：
  - **登录**：邮箱 + 密码；「忘记密码」入口。
  - **注册**：邮箱 + 密码 + 邀请码（格式如 K7M2-QF9W）→ 邮箱收到 6 位验证码 → 六个格子输入（支持整串粘贴）→ 完成。
  - **忘记密码**：邮箱 → 收验证码 → 设新密码。
  - 需要「没收到验证码？请看垃圾邮件箱，或 60 秒后重发」的提示。
  - 错误状态：邀请码无效 / 已被使用、验证码错误、密码错误。
- **这一页必须在手机微信里打开也好看、好用**（家长多半在微信里点开链接）。手机上提示一句「打印请在电脑上打开」。

### 3. 首页「今天」

- 现有内容：每个板块一张卡片（纸张缩略图 + 今天练什么 + 进度 + 「打印」按钮）。
- 请提升质感，并给第一次登录的家长一个简短的欢迎 / 三步上手引导（选板块 → 看纸 → 打印），可以关掉。

### 4. 板块页统一样式

以「识字」为样板，给出一套统一的设置面板样式：分段标签、分区卡片、分段按钮、加减步进器、主次按钮、空状态、提示条。其他板块照这套样式统一。

### 5. 拼音板块（按骨架重排）

现在中间放的是一张很长的登记表，纸卷要点按钮才看得到；四种入口和四排按钮长得一样；每题登记要先展开折叠框再点结果。请改为：

- **中间**：A4 纸卷预览（纸卷内容已定稿，不改）。
- **顶栏摘要**：今日重点 + 组数 + 进度，如「观察 b、d、p、q · 5 组 · 已练 2 组」。
- **右侧面板**：
  - 分段标签：今日 / 专题 / 课程 / 历史
  - 「为什么练这个」一句话（如「昨天 b、d 单独都读对了，读 bā 时需要提示，今天换两个音节再试」）
  - 分组进度条：第 1 组 → 第 2 组 → …，每组显示状态（未练 / 已记 3/4 / 做完），当前组高亮。「换题再试」（卡住时才做）和「试一试」（有余量再做）两类组要和普通组区分开。
  - 当前组登记：每题一行 = 题号 + 题目（大字）+ 三个小按钮〔提示了〕〔没读出〕〔跳过〕。顺利的题什么都不点。点了〔提示了〕或〔没读出〕后，这一行展开一个小输入框「读成什么」，读音题再加一个「是声调错」勾选框。
  - 组底部：主按钮「本组做完」；次要操作「做到一半停了（选最后一题）」；有题卡住时出现「转教学，换题再试」。
  - 家长教学卡（先观察 / 怎么讲 / 示范 / 引导 ①②），卡住时展开，平时折叠。
  - 题目字号：分段按钮 26 / 32 / 40。
  - 「孩子视图」：把当前组题目超大字号显示给孩子在屏幕上读。
  - 全部做完：显示「已保存」+「下次建议：……」。
- **专题**：10 类（字形看混、相近声母、复韵母、鼻韵母、声调、两拼、三拼、整体认读、书写规则、词句应用），每类 1–8 项；**课程**：20 课，每课 1–3 项。做成目录，每项标出状态：没练过 / 待复核（附日期）/ 已稳固。点一项后，中间出现该项纸卷。
- **历史**：按日期列出出过的卷（日期、卷号、重点、已练几组），卷号要醒目（家长对着纸上印的卷号找卷）。点开可以补登记。

### 6. 页脚 / 关于

在板块栏底部或首页底部放：关于练习纸、隐私说明（只存邮箱和练习记录，不做他用）、意见反馈（「有问题请在家长微信群里说」）。

## 五、硬约束

- **打印出来的纸一律不改**：各板块的纸张内容和排版都已定稿，本次只改纸外面的界面。纸张预览是 210mm 宽的白纸。
- **国内必须能打开**：不能用 Google Fonts 或其他国外字体 / 图标服务。界面字体用系统字体（苹方 / 微软雅黑）；拼音题目用站内自带的「Pinyin Kids」字体（单层 ɑ、ɡ，和课本一致）。
- 网站整体（body）的字体和行高不要改，纸卷会继承它。
- 颜色沿用：蓝 `#2a55c9` 表示可操作 / 选中，红表示错，绿表示已学。
- 不要渐变背景、emoji 装饰、左侧彩色竖条卡片、Inter / Roboto 这类常见字体。要沉稳、干净、有质感，适合家长使用，不要做成花哨的儿童风格。
- 以电脑 1280–1600px 宽为主；900px 以下整页滚动、右侧面板排到纸下方即可。**登录页例外，要认真适配手机。**
- 纯 HTML / CSS 实现（不用 React 等框架）。

## 六、请交付

1. 图标套装（SVG）：标识、标签页图标、手机桌面图标、12 个栏目图标。
2. 登录 / 注册页：电脑版 + 手机版，含注册填验证码、出错两种状态。
3. 首页「今天」：首次登录（带欢迎引导）+ 日常两种状态。
4. 板块页统一样式（以识字为例）。
5. 拼音：今日练习（未开始 / 做到一半有题卡住 / 全部做完）、专题目录、课程目录、历史列表、孩子视图。
6. 页脚 / 关于。
