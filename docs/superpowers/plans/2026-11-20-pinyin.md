# 拼音巩固实施计划

**目标**　从首页打开一张约五分钟的拼音卷，能在纸上或屏幕上练习、登记和复核。

**设计**　[拼音巩固板块](../specs/2026-11-20-pinyin-design.md)。沿用静态 HTML、原生 JS、store.js、A4 打印确认和 Node 校验脚本。

1. 在 `tools/check-pinyin.js` 固定首次卷、半组登记、结果修正、跨日换题和休息日规则。用 `js/pinyin-data.js` 保存方向、课程及可审查的素材，用 `js/pinyin-core.js` 提供 `makeSheet(date, state, options)` 和 `derive(sheets, marks, date)`。进度从题目证据重算。
2. 在 `js/pinyin-storage.js` 按卷号保存卷面，按题号保存结果。补登用原日期与原题。验证同日离线双卷能分别定位，单题撤销覆盖旧记录，超过 200 个同步键时推送分批。
3. 在 `pinyin.html`、`css/pinyin.css` 和拼音界面脚本实现今日卷、专题、课程、历史、分支教学和打印。验证空卷、半组收工、刷新、家长标记和打印版式。
4. 在首页加入口和摘要，沿用同一计算逻辑。跑拼音、首页、存储和同步校验，再用浏览器检查打印链路。

音节表列出 407 个基础拼写，并校验口头题与词库使用的音节。拼写口径参考[《汉语拼音正词法基本规则》](https://www.moe.gov.cn/ewebeditor/uploadfile/2015/01/13/20150113091717604.pdf)。

家庭实际用时和真实账号跨设备补登列入交付验收。
