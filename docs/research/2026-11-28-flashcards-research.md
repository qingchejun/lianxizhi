### 4. 中文实体卡与教材配套

| 产品 | 做法 |
|---|---|
| 洪恩识字卡 | 一字一卡、正反两面讲一个字：插画字形、拼音、标准字、词、句、古文字写法，背面二维码看动画。**卡上的词句只用学过的字**（「字不离词，词不离句」）；手掌大小、加厚覆膜。与 App 配合 |
| 四五快读 | 书后字卡可拆，背面是拼音；先字后词。**家长打钩法**（豆瓣家长分享）：会了打一钩、秒答打两钩，一天最多两钩；满四钩收起来，五天后复测，不会的再认两次、再隔五天。大量游戏：多了哪张/少了哪张、拍苍蝇、点老五、吹大风、买菜、障碍赛跑、「读出来的归你」筛难字 |
| 口算卡（老师文章） | **一题一卡、只写算式不写得数、不做双面**（翻面耽误速度）；扑克牌或名片大小、厚卡纸；重点是 20 以内进位加法 20 道 + 退位减法 36 道；洗牌后同桌互考、秒表计时、记每遍用时 |
| 拼音卡 | 标准 63 张：声母 23、韵母 24、整体认读 16；有的韵母带四声。旧博客提醒：市售卡常用英文字体，a、g 带「小尾巴」，和课本不一样 |
| 斑马 | 英语闪卡机、点读卡、思维机题卡（实体卡 + 机器），走硬件路线 |

### 5. 练法与研究（怎么用卡）

| 方法 | 要点 | 证据 |
|---|---|---|
| Leitner 盒 | 3 盒：盒 1 每天、盒 2 每 3 天、盒 3 每 5 天；对了升一盒、错了回盒 1。给孩子简化成「在学的一小堆每天过、会了的一堆每周过一两次」 | 经典做法，间隔复习的纸面版 |
| 递增复习 Incremental Rehearsal（Tucker） | 一组里大部分是会的、少量是新的（常见 1 新 : 8–9 熟），新卡一张张插进熟卡里反复过，一轮约 3 分钟 | 多项研究支持，保持效果在几种闪卡练法里最好（Burns & Boice 2009）；有研究认为「交错练」更省时 |
| Rocket Math | 卡片按顺序编码，**工作牌永远只有 12 张，其中只有 3 张是新的或难的**；家长拿答案听孩子说，**错了或犹豫都按规定流程纠正**；每天几次、每次 3–4 分钟；文档写明闪卡更适合在家一对一 | 商业项目，有研究基础 |
| XtraMath | 每道限时：默认 6 秒，先准确再练到 3 秒；只有测验改分 | 3 秒内答出算「真正熟练」 |
| Brainscape | 每张卡自评 1–5，低分早回来、5 分几乎不再出 | 自评驱动，不是记忆模型 |
| 蒙台梭利三段卡 | 控制卡（图+字）、图卡、字卡，孩子配对，再用控制卡自己核对 | 适合幼儿，「自己能核对」 |
| 多曼快闪（0.5–1 秒/张） | 越快越好、越早越好 | 无同行评审证据，批评多，不做 |
| 计时 | 争议：NCTM 反对计时测验；Fuchs 的研究里 60 秒限时练让孩子每天答对更多；英国研究：有焦虑的孩子在时间压力下学得更少，没压力时焦虑与学习量无关 | 计时可以有，但别做成高压 |

## 二、关键发现

1. **别家生成器几乎都「印完就不管」**（文档写明）：Printmigo 明说没有复习、不保存；练学宝只在说明里写了 1-3-7-14-30 天。中文里只看到 zitieapp 按「新字 + 复习字」每天出一包。
2. **好用的练法都是「一小撮难的混在会的里」**：Rocket Math 12 张里 3 张难；递增复习 1 新配 8–9 熟；四五快读打钩满四钩收起。这和我们「上一张错的、下一张再出」是同一个思路，我们已经有错题 / 错字数据。
3. **印法三种，各有拥护者**：对折卡（不用对齐，Twinkl、Printmigo 都有）最省心；双面要测试页和微调；老师做口算卡反对写答案、反对双面——要的是速度，答案家长心里有或看清单。
4. **一卡一事、词句不超纲**：洪恩卡上的词句只用学过的字；我们识字已有统编字表和学到哪一课。
5. **家长需要「怎么玩」**：Kumon 附家长卡，四五快读一堆游戏，三段卡自带核对。光给卡、不给玩法，家长很快就不用了（推断）。
6. **字体**：拼音卡的 a、g 要单层写法，我们拼音已经有拼音字体。

## 三、对我们的初步想法（待站长定，未实施）

1. 闪卡是一种「打法」，不是新板块：口算、识字、拼音页各加「练习纸 | 闪卡」，用各自已有的进度和错题出卡。
2. 一套一页 A4，对折卡（剪开对折，背面是答案 / 拼音组词），可选「只印正面」（老师式口算卡），附一行玩法。
3. 一套 12 张左右：约 3 张是错过的或新学的，其余是学过的（Rocket Math / 递增复习的比例），三四分钟过一遍。
4. 用法印在纸上：「会了 / 犹豫 / 不会」三堆（简化 Leitner），不会的家长在打分栏点一下，下一套还出。
5. 不做快闪、不强制计时（计时作为可选玩法）。
