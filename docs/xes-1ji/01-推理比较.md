## 4. 知识点 × 题型

B01 比长短（3 个题型）：
- 绕绳子 `rope` ← K2 K3（L3 两个条件同时用）
- 方格排长短 `grid` ← K4 K5（L1 整格 3 根问最长/最短；L2 4 根排序；L3 5 根含半格、横竖混放）
- 方格路线 `route` ← K6 K7 K8（L1 只有横竖线、有绕路凸起；L2/L3 加斜线，按「同类比多少」能判断的才出）
- K1 目测会骗人：只放讲解页「先想一想」（错觉图），不出题。

B02 比轻重（另做）：单天平 ← K9；多天平排序 ← K10 K11；两边去掉相同 / 两个比一个 ← K12 K13（`def: false`）。K14 只放讲解页。

## 5. 课的设计（B01）

- 编号 B01，id `bichang`，名「推理比较：比长短」，stage `L1B`。
- 讲解页（新版结构，试点）：先想一想（错觉图）→ 三张招式卡（数圈数看粗细 / 数格子 / 路线分类数），每张卡：要点 + 步骤 + 小心 + 生成器例题 → 用哪一招 → 口诀。
- 口诀：「眼睛会骗人，比长短要动脑：绳子先看粗细再数圈，铅笔数格子，路线分开数。」（视频可再提炼）
- 答案：rope 答「第 N 根」；grid 答编号顺序（如「2 号 → 1 号 → 3 号」）或最长/最短的编号；route 答人名或「一样长」。
- 程序验证：rope 用 周长×圈数 计算长度；grid 用格数；route 用 斜线×1.4 + 横竖线 计算，并要求按类比较能直接判断（不出要算 1.4 的题）。
