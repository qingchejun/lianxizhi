## 4. 知识点 × 题型（B11）

- 认线 `kind` ← K1 K2 K3 K4 K5（M1）。一排编号的线，填「直线、射线、线段」各是哪几号。入门 5 个，只有直线、射线、线段；提高 6～7 个，加 1～2 条折线、曲线；挑战 8 个，加带端点的折线、曲线（有两个点也不是线段），还故意把直线画短、线段画长。
- 平行和垂直 `rel` ← K6 K7 K8（M5）。一排编号的两条线，填平行的、垂直的。垂直一律画小板凳（不画的话一年级量不出 90°，和斜着交叉的分不开）；斜着交叉的夹角取 35°～60°，一眼就不是直角。入门 5 个（垂直是横竖的「十」）；提高 6 个，加一组「没碰到但不平行」（夹角 ≥ 22°，越往一头越窄），垂直可以斜着放；挑战 7 个，再问「相交的有」——垂直也是相交（陷阱），平行线长短、位置错开也还是平行。挑战档不放「没碰到但不平行」的，因为这时问相交会有歧义。
- 能不能相交 `meet`，`def: false` ← K1 K2 K3 K9（M5）。A～D 四组线，选能相交的。入门只有直线和线段；提高加射线；挑战加平行的两条直线、射线往回才碰得到（有点那头不能延长）、两条线段延长才碰到（线段不能延长）这些陷阱。程序保证：能相交的，交点就在图框里、离端点至少 6px；不能相交的，交点离能延长的范围至少 14px，或者平行。
- 数平行线 `par` ← K6 K10（M6）。入门 3～4 条平行线；提高 4～5 条，或 3～4 条加一条斜线干扰，或三角形里 3～4 条横线（含底边）；挑战三角形里 4～5 条横线，或两个方向的平行线（横 a 条、竖/斜 b 条，答 a、b 各自配对再相加）。
- K4 折线、曲线只在认线里当干扰，不单独问。K5 不单独出题，在 `kind` 挑战档和讲解页「小心」里。K8 直角的分类（锐角、钝角）归 B12。
- 每个 K 都至少被一个题型练到：K1～K5 `kind`，K6～K8 `rel`，K9 `meet`（K1～K3 也在这里用到），K10 `par`。

## 5. 课的设计（B11）

- 编号 B11，id `renxian`，名「线角初步：认识线」，stage `L1B`，lesson.v2。卷子标题「认识线练习 · 提高」。
- 讲解页：今天学会 → 先想一想（手电筒的光能照多远？尺子的边呢？）→ 先认识（直线 / 射线 / 线段 / 折线和曲线 / 平行 / 相交和垂直，每张卡带图）→ 第一招 看端点认线（kind）→ 第二招 看两条线的位置（rel、meet）→ 第三招 编号数平行线（par）→ 用哪一招 → 口诀。
- 口诀：「没有端点是直线，一个端点是射线，两个端点是线段；永远碰不到是平行，交成小板凳是垂直；直线射线能延长，线段到头不能长；数平行线先编号，两条一组按顺序。」
- 图：黑白内联 SVG。线 2.4 宽，端点实心圆点；垂直画小板凳；所有题图 `fig-big`。答案带多个空的（认线、平行垂直）用新加的 `ansFields`：答题行变成「直线：____　射线：____　线段：____」。
- 答案：kind「直线 ③⑥；射线 ①；线段 ②④」；rel「平行 ①④；垂直 ③」（挑战加「相交」）；meet「A 和 D」；par 数字（组）。
- 程序验证（`check-aoshu-gen.js` 的 `checkRenxian`，不看 key、直接量题干 SVG）：kind 每个编号数圆点、看是不是一根直线，重算三类；rel 量每对线的方向，差 0° 平行、差 90° 垂直（还要有小板凳），挑战档相交 = 画出来真的交叉；meet 从圆点判断哪头能延长，重算交点；par 把所有线按方向分组，每组 n 条算 n(n−1)/2 再相加。
