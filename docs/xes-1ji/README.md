# 学而思 1 级 × 练习纸 对照表

讲义：用户本机 `~/Downloads/01、1级-2022版《学而思秘籍 小学数学思维培养》讲义/`（20 讲 + 参考答案，扫描版 PDF，无文字层）。
每讲约 28 页：6 个「好方法」，每个 = 例题 + 解析 + 2～3 道举一反三/挑战自我，末尾一道「探索知识巅峰」，共约 18 道练习。
用法：只当「教什么、按什么顺序、分几招」的参考；题目一律用出题器参数化生成，不搬原题、原图、原解析。

判断：`补充版` = 和已有课重叠，单独做一课「XX（补充）」，只讲已有课没讲过的知识点和题型，不动原课、不重做原视频；`已覆盖` = 读完发现没有新东西，跳过；`新课` = 全新知识点；`拆散` = 杂烩讲，按方法分进各补充课/新课。
**表里的判断只根据目录和两讲正文，是初判**；每讲拆题时读完整讲再定（可能改判、可能一讲拆成两课）。

编号：新课和补充版都进「L1 补充」系列（stage `L1B`，编号 B01、B02……按做的先后排，大体跟学而思讲序走），放在 L1 之后、L2 之前；首页「今天学」按大纲顺序推荐，所以学完 L1 会接着推 L1 补充。
每讲做完拆题后在「状态」列写日期和结果（例：`2026-11-12 新课 tuili 已上线`），拆题笔记放 `docs/xes-1ji/<讲号>-<名>.md`。
