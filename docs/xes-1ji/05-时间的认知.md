## 4. 知识点 × 题型

B03 认识钟表：整时和半时（3 个题型）：
- 看钟写时刻 `read` ← K1 K2 K3 K4 K5（L1 一个整时；L2 一个半时为主、偶尔整时；L3 两个钟：几时半和下一个整时放一起，如 5:30 和 6:00，专门练「过几就是几」）
- 哪个钟是 X `pick` ← K2 K3 K4 K5（练 2 改成选一选。L1 整时，三个钟：对的、长短针颠倒、差一时；L2 半时，三个钟：对的、少一时的半时（「快到几」陷阱）、同一时的整时；L3 四个钟，题目有时写「几时半」有时写「几:30」，再加一个长短针颠倒的）
- 画钟 `draw`，`def: false`（要家长对着解析里的图批改）← K5 K6 K7（L1 画整时；L2 画半时；L3 两个钟一整一半，或巅峰题：两针重叠 / 成一条直线的整时）。都要再写电子计时法，答案栏能写字。
- K2「时针走得慢、分针走得快」只在讲解页「先认识」和视频里讲，不单独出题。
- K8～K13 归 B04。

## 5. 课的设计（B03）

- 编号 B03，id `zhongbiao`，名「认识钟表：整时和半时」，stage `L1B`，lesson.v2。
- 讲解页：今天学会 → 先想一想（手机上 5:00，墙上的圆钟呢？）→ 先认识（钟面 1～12 / 两根针 / 电子计时法）→ 第一招 读钟 → 第二招 对一对 → 第三招 画钟 → 用哪一招 → 口诀。
- 口诀：「短的时针长的分，分针指 12 是整时，分针指 6 是半时；时针过几就几时，写成几:00、几:30。」
- 图：黑白内联 SVG 钟面：圆圈、60 个小刻度（每 5 个加粗）、1～12，时针短粗（5 宽）、分针长细（2.2 宽），中心圆点；时针按真实角度画（半时正好在两个数中间）。一个钟用 `fig-big`，一排三四个钟也用 `fig-big`。
- 难度：入门 = 只有整时；提高 = 半时为主；挑战 = 整时半时放一起比、长短针颠倒的干扰、巅峰题。
- 答案：read 答「5:30」或「① 5:30　② 6:00」；pick 答「②」；draw 答电子计时法「4:30」，解析里画出正确的钟。
- 程序验证：`check-aoshu-gen.js` 的 `checkZhongbiao` 从 key 里的时刻独立重算答案；pick 检查选项互不相同、正好一个对；把题干 SVG 里两根针的角度量出来，和 key 的时刻对得上。

## 5. 课的设计（B04）

- 编号 B04，id `zhongbiao2`，名「认识钟表：几时几分」，stage `L1B`，lesson.v2。只和已做视频的课对照：B03 已讲认针（K2）、整时半时（K3 K4）、画针长短（K6），这里一句带过（「B03 我们会读整时和半时了」），不再讲。
- 讲解页：今天学会 → 先想一想（7:20 的钟，分针既不指 12 也不指 6）→ 先认识（大格和小格 K8 / 5 个 5 个数 + 1 时 = 60 分 K12 / 补 0 K10）→ 第一招 读几时几分（read、pick）→ 第二招 画几时几分（draw）→ 第三招 排先后（order）→ 用哪一招 → 口诀。
- 口诀：「时针过几就几时，快到下个还不算；分针 5 个 5 个数，零头小格接着数；分不满 10 前补 0。」
- 题型（分都避开 :00 和 :30，那是 B03 的；两根针夹角 ≥ 15°，免得压住小格数不清）：
  - 看钟写几时几分 `read` ← K8 K9 K10 K11。入门：分针指在数上（5 的倍数）；提高：有零头小格，四成是零几分（练补 0）；挑战：两个钟，快到整时（h:45～59）和刚过整时（h+1:01～14），两根时针都在 h+1 附近（练 6、练 15 的陷阱）。
  - 哪个钟是 X `pick` ← K9 K10 K11。干扰钟每个对应一个常见错：把分针指着的数当分（7:02 ← 分针指着 2 的 7:10）、时针快到 h 的 (h−1) 时、逆着数小格（h:60−m）、时不对。入门 3 个钟（分是 5 的倍数）；提高 3 个钟（零几分或 36 分以上，先放「数当分」「时针快到」）；挑战 4 个钟。
  - 画几时几分 `draw`，`def: false` ← K6 K9（M5）。入门分是 5 的倍数；提高有零头；挑战画快到整时和刚过整时一对。都写电子计时法，解析放标准答案图。
  - 排先后 `order` ← K9 K11 K13（M6）。中午到傍晚三件事（钟下写事情），按先后填序号。入门：下午 1～5 时、时都不同；提高：加一个中午 12 时几分（12 数大却最早）；挑战：12 时几分 + 快到整时和刚过整时一对。
- K12「1 时 = 60 分」只在「先认识」讲，不单独出题（一年级不算经过时间）。K13 不出「早上/晚上」判断题：钟面看不出上下午，只能靠情境，放进排先后的「中午到傍晚」里练。
- 程序验证：`check-aoshu-gen.js` 的 `checkZhongbiao2` 从 key 重算答案（排先后按 12 时最早独立排序），量题干两根针的角度、长短、夹角，查各档范围、不出整时半时。
